# 网易云音乐歌单分析

Python 数据分析案例与离线交互展示。围绕七个问题，分析标签搭配、热度分层、播放表现、内容主题、收藏表现、曲目相似及评论场景线索。

## 数据与主要结果

| 内容 | 范围或结果 |
| --- | --- |
| 历史主体 | 46,613 条歌单，采集日期未知，属于目的性样本 |
| 独立补充 | 635 条歌单，快照日期见数据说明 |
| 定向刷新 | 89 个历史歌单 ID，完整曲目数量已核验 |
| 评论观察 | 3,020 条去重歌单评论；82 个歌单有观察 |
| 标签关联 | 34 条候选规则中，31 条在核验集完整达标 |
| 歌单分层 | 主体 46,610 条，K=2；拟合抽样轮廓约 0.505，留出约 0.500 |
| 内容回归 | 测试 R²(log) 约 0.055，解释力较弱 |
| 收藏比值分类 | 按验证集选择 MLP，测试 AP 约 0.528、ROC-AUC 约 0.748 |
| 曲目补全代理 | 曲目近邻 Recall@10 约 1.49%，绝对召回仍低 |

以上是本样本内的分析与离线评价，不代表全平台分布、个人收藏概率或业务上线收益。评论规则标签未经人工复核。
